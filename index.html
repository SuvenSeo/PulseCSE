Why this project works

A complete web technology prototype with clear viva explanations.

It has enough technical depth to explain data structures, DOM manipulation, state persistence, responsive design, and alert logic without requiring a risky live financial API.

01

Watchlist Dashboard

Users can track selected CSE counters, view price movement, and inspect recent disclosure highlights.

02

Rule-Based Alerts

Alert rules simulate price-above, price-below, percentage move, disclosure, and volume-spike events.

03

Local Persistence

Alerts, watchlist changes, and history are saved in the browser using LocalStorage.

04

Academic Safe Scope

The project is original, explainable, and avoids copying third-party repo code or claiming real trading signals.
