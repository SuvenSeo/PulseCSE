Project Explanation

What PulseCSE is and how it works

A full-stack Sri Lankan stock alert cockpit with a premium frontend, Python backend, SQLite persistence, alert engine, simulator, and notification adapters.

Problem

Retail investors often miss price movements and company announcements because they manually check multiple sources. PulseCSE demonstrates how a web app can centralize watchlists, alert rules, and alert history.

Scope

This version runs in two modes: static demo mode and backend-connected mode. The backend uses a mock market adapter by default so local runs are deterministic and safe. Telegram and webhook adapters are included for real notification delivery when credentials are provided.

Implementation

The project uses semantic HTML, responsive CSS, modular JavaScript, LocalStorage, DOM rendering, form validation, canvas charting, deterministic scenario simulation, tests, and a separated rule evaluator for mock alerts.

Engineering Highlights

You can explain watchlist arrays, alert objects, SQLite + LocalStorage, event listeners, responsive grid layouts, pure alert-engine functions, and how deterministic scenarios evaluate alert conditions.
